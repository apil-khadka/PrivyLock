Protection without the clutter.

AppLock lives in the menu bar and keeps its state across restarts, with controls designed around the way macOS users actually work.

🔐

Touch ID + password

Use Touch ID when it is available, with the secure macOS login-password fallback when it is not.

⚡

Launch protection

Locked apps are stopped before or immediately after launch, with a watchdog for race conditions.

🌙

Automatic locking

Lock everything on screen lock or after a configurable period of inactivity.

🧭

Clear at a glance

See every protected app, its icon, bundle identifier, and current lock state in one place.

🛡️

Safe controls

Removing locked protection or quitting while apps are protected requires owner authentication.

💾

Local by design

Authentication stays inside macOS protected services; AppLock stores only its local configuration.

Get started in seconds.

Download the latest release, move AppLock wherever you keep your apps, and add protection from the menu-bar shield.

1. Download AppLock-macOS.zip
2. Unzip and open AppLock.app
3. Add an app to protect
4. Choose Lock
# Build from source
git clone https://github.com/apil-khadka/AppLock.git
cd AppLock
./build.sh release
open build/AppLock.app
AppLock is an open-source macOS utility. A determined privileged process can bypass any user-space app locker; use it as a privacy and convenience layer.
