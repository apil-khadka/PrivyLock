Protection without the clutter.

PrivyLock lives in the menu bar and keeps its state across restarts, with controls designed around the way macOS users actually work.

🔐

Touch ID + password

Use Touch ID when it is available, with the secure macOS login-password fallback when it is not.

⚡

Launch protection

Locked apps are stopped before or immediately after launch, with a watchdog for race conditions.

🌙

Automatic locking

Lock everything on screen lock or after a configurable period of inactivity.

🧭

Clear at a glance

See every protected app, its icon, bundle identifier, and current lock state in one place.

🛡️

Safe controls

Removing locked protection or quitting while apps are protected requires owner authentication.

💾

Local by design

Authentication stays inside macOS protected services; PrivyLock stores only its local configuration.

Install once. Stay protected.

PrivyLock is an open-source macOS utility. A determined privileged process can bypass any user-space app locker; use it as a privacy and convenience layer.
